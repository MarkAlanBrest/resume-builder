💡 How to Write a Strong Job Duty

  • Start with an action verb: Maintained, Operated, Installed, Inspected, Assisted…
  • Be specific: Name the tools, equipment, or processes you used
  • Skip "I": Write "Diagnosed brake issues" not "I diagnosed brake issues"
  • Add a detail or result: "Performed oil changes on 8–10 vehicles per shift"
