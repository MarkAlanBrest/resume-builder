Writing Guidance

If you select 3 boxes, no extra writing is needed. If you select 2 boxes, add a short sentence (about 20+ characters). If you select 1 box, add a few sentences (about 40+ characters). If you select 0 boxes, add a solid paragraph (about 60+ characters).

Tip: Fewer boxes = more detailed writing expected.
